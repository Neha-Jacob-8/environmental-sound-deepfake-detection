# Results dashboard

Interactive view of the model results: leaderboard, per-generator EER matrix,
training curves and generator profiles.

```bash
cd web
npm install
npm run dev        # http://localhost:5173
npm run build      # static site in web/dist
```

## The data is generated, not hand-written

`src/data/researchData.ts` holds the measured constants — `MODELS`,
`PER_GENERATOR`, `CURVES`, `CONFIDENCE`. **Do not edit those by hand.** They are
rewritten from `results/tables/` by:

```bash
python3 -m src.analysis.export_web_data          # from the repo root
python3 -m src.analysis.export_web_data --check  # fail if stale, for CI
```

Retrain a model and the dashboard would otherwise keep showing the old numbers
with nothing to signal they are stale. Run the exporter after every training
run. Everything else in that module — the interfaces, generator descriptions,
palette, dataset stats — is prose and is left alone by the generator.

## Scope

This covers the **results** only. The planned interactive detector, the
"can you tell?" listening challenge and the embedding-space explorer are
specified in [`docs/ui-prompt.md`](../docs/ui-prompt.md) and are not built here.
Their assets are ready: `docs/ui-data.json`, `docs/model/logmel_cnn.onnx` and
the 80 clips in `docs/audio/`.

## Notes

- Palette is fixed and validated for colour-vision deficiency; a model keeps its
  colour however the table is sorted.
- Light/dark follows the system setting, with a manual override.
- Generated by Google AI Studio from `docs/ui-prompt.md`, then adapted: the
  invented breadcrumbs and paraphrased title were replaced with the project's
  real ones, unused AI Studio scaffolding was removed, and the data was wired to
  the exporter above.
